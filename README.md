# Crawl4AI Practice Repository

A minimal practice environment for experimenting with **Crawl4AI**, a lightweight and flexible web-scraping framework built for AI workflows.

## What This Repo Contains
- Simple examples using **Crawl4AI** to fetch and parse web content  
- Practice scripts for crawling pages, extracting text, and cleaning data  
- Basic utilities to prepare scraped text for LLM pipelines  

## Installation
```bash
pip install crawl4ai
```
